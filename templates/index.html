Getting Started Guide

Quick Start

  1. Set up API Keys: Go to Settings and add your Firecrawl API key (required). The Groq AI key is optional for AI descriptions.
  2. Phase 1 - Find Products: Enter homepage URLs to discover product links automatically.
  3. Phase 2 - Extract Data: Scrape detailed information from the discovered product URLs.
  4. Export Results: Download your data as CSV in various formats (JustSell, WSMarketplace).

Phase 1: URL Discovery

This phase helps you find product URLs from main category or homepage URLs.

Input: Enter homepage or category URLs (one per line)
Process: The system extracts product links from sitemaps and pages
Output: List of product URLs ready for detailed scraping
Tip: For paginated sites, manually add URLs from page 2, 3, etc. for complete coverage

Intelligence Engine Selection

Choose the optimal AI extraction method for your target websites.

WSMarketplace PRO: Complete extraction with detailed specs, price validation, and comprehensive data - optimized for wholesale marketplace format
JustSell PRO: Shopify-compatible format with hierarchical categories and e-commerce fields - optimized for JustSell integration
Auto-Save: Your selection is saved automatically and applies to all future scraping sessions

Phase 2: Data Extraction

Extract detailed product information from URLs.

Auto-SKU: Automatically generates unique product codes when missing
AI Descriptions: Uses Groq AI to create professional descriptions (requires API key)
Sessions: Data is saved to your current session automatically
Best Practice: Process 50-100 URLs at a time for optimal performance

Pro Tips

  • Use Tab to accept pagination suggestions in URL fields
  • Enable "Auto-save progress" to prevent data loss
  • Check API status in the top status bar before starting
  • Finalize sessions regularly to keep data organized
  • Use the dark mode toggle for comfortable viewing
